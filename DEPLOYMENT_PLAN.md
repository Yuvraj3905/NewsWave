# NewsWave Free + Instant Deployment Plan

Zero-cost stack with near-instant response. Two paths: Render+pinger or Koyeb.

## Stack Overview

```
[Vercel] Next.js frontend  ->  [Render | Koyeb] NestJS API  ->  [Neon] PostgreSQL
                                          |
                                          +-> [Cloudinary] Media
                                          +-> [Make.com webhook] -> Social
```

---

## Option A (recommended) - Render + UptimeRobot keep-warm

| Layer | Provider | Cold start | Cost |
|---|---|---|---|
| Frontend | Vercel | 0 | Free |
| Backend | Render Free | ~0 if pinged | Free |
| Keep-warm | UptimeRobot 5-min ping `/health` | - | Free |
| DB | Neon (Postgres serverless) | ~50ms | Free 0.5 GB |
| Media | Cloudinary | - | Free 25 credits / mo |
| Analytics | GA4 | - | Free |

### Steps

1. Push repo to GitHub.
2. **Vercel** -> import repo -> root `frontend/` -> env:
   - `NEXT_PUBLIC_API_URL=https://newswave-api.onrender.com/api`
   - `NEXT_PUBLIC_SITE_NAME=NewsWave`
   - `NEXT_PUBLIC_GA4_ID=G-XXXXXXXXXX`
   Deploy. ~2 min.
3. **Neon** -> new project `newswave` -> copy connection string.
4. **Cloudinary** -> copy `Cloud name`, `API Key`, `API Secret`.
5. **Render** -> New Blueprint -> repo -> auto-detects `render.yaml` -> set:
   - `DATABASE_URL` (Neon)
   - `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`
   - `SEED_MANAGER_USERNAME=admin`, `SEED_MANAGER_PASSWORD=<strong>`
   - `CORS_ORIGINS=https://<vercel-url>`
   - `PUBLIC_SITE_URL=https://<vercel-url>`
   - `SOCIAL_WEBHOOK_URL` (from Make.com)
   Deploy. ~5 min.
6. **UptimeRobot** -> free monitor -> `https://newswave-api.onrender.com/health` -> interval 5 min. Keeps backend warm 24/7.
7. Update Render `CORS_ORIGINS` + `PUBLIC_SITE_URL` to final Vercel URL. Redeploy.

Total: ~10 min, $0/mo.

## Option B (truly always-on free) - Koyeb

Same stack, swap Render for Koyeb (no sleep on free tier, drop pinger).

1. Sign up koyeb.com -> New Service -> GitHub -> backend dir.
2. Build: `pnpm install --no-frozen-lockfile && pnpm build`
3. Run: `node dist/main.js`
4. Plan: free nano instance.
5. Env vars: identical to Render (see Option A step 5).
6. Use Koyeb URL for `NEXT_PUBLIC_API_URL` + CORS.

Faster, simpler. Slight resource cap (512 MB RAM).

## Social Distribution (Make.com)

1. New scenario in Make.com.
2. First module: `Webhooks > Custom webhook`. Copy URL.
3. Add URL to backend env as `SOCIAL_WEBHOOK_URL`.
4. Wire downstream:
   - `X (Twitter) > Create Tweet` -> `{{title}} {{url}}`
   - `Facebook Pages > Create Post` -> `{{title}}`, `{{image_url}}`
   - `Instagram for Business > Photo Post` (Business account required)
5. Webhook payload schema:
   ```json
   {
     "id": "uuid",
     "title": "string",
     "slug": "string",
     "description": "string",
     "image_url": "string",
     "url": "https://newswave.vercel.app/article/<slug>",
     "categories": ["Sports"],
     "locations": ["Punjab"],
     "published_at": "ISO 8601 timestamp"
   }
   ```

## Google Analytics 4

1. Create GA4 property at analytics.google.com.
2. Copy Measurement ID `G-XXXXXXXXXX`.
3. Add to Vercel env as `NEXT_PUBLIC_GA4_ID`.
4. Redeploy. Frontend loads gtag automatically.

## Pre-flight Checks

- `frontend/.env.local` and `backend/.env` ignored in git (`.gitignore` covers).
- Set strong `SEED_MANAGER_PASSWORD`. Rotate after first login.
- `JWT_SECRET` auto-generated by Render via `generateValue: true`.
- Verify `CORS_ORIGINS` matches final Vercel URL exactly (no trailing slash).

## First-time Smoke Test

1. `https://newswave-api.onrender.com/health` -> `{"status":"ok"}`.
2. `https://newswave-api.onrender.com/api/docs` -> Swagger.
3. Visit Vercel URL. Categories + locations populated in header.
4. Login `/admin` with seed credentials. Change password.
5. Publish test article. Verify:
   - Visible on home + direct URL.
   - Latest sidebar populated.
   - Webhook fires, social channels post.

## Local Development

```bash
pnpm install
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env.local

pnpm dev:backend   # http://localhost:4000
pnpm dev:frontend  # http://localhost:3000
```

Local Postgres via Docker:

```bash
docker run --name newswave-pg -e POSTGRES_PASSWORD=postgres \
  -e POSTGRES_DB=newswave -p 5432:5432 -d postgres:16
```

```
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/newswave
DATABASE_SSL=false
```
